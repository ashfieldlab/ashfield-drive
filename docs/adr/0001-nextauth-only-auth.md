# 인증 모드는 NextAuth + JWT 다이렉트만 지원한다

> **대체됨 (2026-10)** → [ADR-0023](0023-better-auth-jwks.md) Better Auth + JWKS. 게이트웨이 세션 차용(구 ADR-0021, 삭제)도 함께 폐기됐다. 아래는 결정 당시 기록이다.

이전 스켈레톤은 NextAuth 모드와 게이트웨이(`ashfield_sid`) 모드 두 가지를 동시에 지원했다. 게이트웨이 모드는 stateful 세션 vault + 백엔드의 JWT 검증 부재 + 도메인 라우터 곳곳의 헤더 주입 코드 등 누적 비용이 컸고(별도 진단 문서 참고), 새 서비스는 모두 NextAuth + JWT 다이렉트 패턴으로 가는 것이 더 단순했다. 호환을 위해 두 모드를 유지하면 디폴트가 사실상 무엇인지 흐려지므로, 게이트웨이 모드 코드는 완전히 제거하고 디폴트를 하나로 못 박는다. 게이트웨이가 필요한 기존 서비스는 본 스켈레톤을 출발점으로 쓰지 않는다.
